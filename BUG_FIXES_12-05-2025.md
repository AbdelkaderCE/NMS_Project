# Bug Fixes - December 5, 2025

## Issues Fixed

### Issue 1: Admin Can't Create Activities ✅

**Error**: "Staff profile is required. Only staff members can log activities."

**Root Cause**: 
- Activity controller required a staff profile for all users
- Admin users don't have staff profiles
- Controller was too restrictive

**Fix**:
```javascript
// OLD - Required staff profile for everyone
const staffProfile = await Staff.findOne({ user: req.user.id });
if (!staffProfile) {
  return sendError(res, 400, 'Staff profile is required...');
}

// NEW - Only require staff profile for staff role users
let staffProfile = null;
if (req.user.role === 'staff') {
  staffProfile = await Staff.findOne({ user: req.user.id });
  if (!staffProfile) {
    return sendError(res, 400, 'Staff profile is required...');
  }
  if (staffProfile.position !== 'teacher') {
    return sendError(res, 403, 'Only staff with position "teacher"...');
  }
}

// Admins can create activities without a staff profile
const activityData = { ...req.body };
if (staffProfile) {
  activityData.loggedBy = staffProfile._id;
}
const activity = await Activity.create(activityData);
```

**File Modified**: `server/controllers/activityController.js`

**Impact**: ✅ Admins can now create activities without staff profiles

### Issue 2: Teacher Can't Mark Attendance - "Record Already Exists" ✅

**Error**: "Attendance record already exists for this date"

**Root Cause**:
- Multiple issues combined:
  1. Date normalization wasn't considering timezone
  2. String date "2025-12-05" converted to Date object had timezone issues
  3. Exact date match query failed to find existing records reliably
  4. Spreading `req.body` at end overwrote normalized date

**Fix**:
```javascript
// OLD - Unreliable date handling
const attendanceDate = new Date(date || Date.now());
attendanceDate.setHours(0, 0, 0, 0);

const existingAttendance = await Attendance.findOne({
  child,
  date: attendanceDate,
});

// Spread req.body overwrites our date normalization
const attendance = await Attendance.create({
  child,
  date: attendanceDate,
  status: status || ATTENDANCE_STATUS.PRESENT,
  recordedBy: staff._id,
  ...req.body,  // ❌ This overwrites date with original value
});

// NEW - Robust date handling with range query
let attendanceDate = new Date(date || Date.now());
attendanceDate.setHours(0, 0, 0, 0);

// Use ISO date format for reliable string comparison
const dateString = attendanceDate.toISOString().split('T')[0];

const existingAttendance = await Attendance.findOne({
  child,
  date: {
    $gte: new Date(dateString + 'T00:00:00.000Z'),
    $lt: new Date(dateString + 'T23:59:59.999Z')
  }
});

// Explicitly set fields instead of spreading req.body
const attendance = await Attendance.create({
  child,
  date: attendanceDate,
  status: status || ATTENDANCE_STATUS.PRESENT,
  recordedBy: staff._id,
  checkInTime: req.body.checkInTime,
  checkOutTime: req.body.checkOutTime,
  notes: req.body.notes,
});
```

**File Modified**: `server/controllers/attendanceController.js`

**Impact**: ✅ Teachers can now mark attendance multiple times without false "already exists" errors
